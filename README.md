## 🚀 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 20+)
- npm / bun

### Installation & Development
```bash
# Clone the repository
git clone https://github.com/poomani06/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```
